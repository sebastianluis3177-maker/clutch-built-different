Build Log · November 2026

The First Print

Making them was the hard part. The first print came back with the map stretched out of shape. The streets were warped, the grid was off — it didn't look like the neighborhood at all.

So the file got rebuilt from scratch. Clean lines, straight grid, logo exactly where it belongs. Every piece checked again — four legs, two front and two back, plus the four inside pocket bags.

Getting the print right

The map has to read straight or the whole thing falls apart. The logo sits low on one leg. The pocket bags carry the "clutch built different" script on the inside. Nothing on the shorts is random — every piece of the pattern has a job.

It took a few rounds to get there. The new print sheet finally looked right: the map not deformed, the grid straight, the logo where it belongs. That's when the shorts started looking like the idea.

Accounts — everyone who signed up.


Owner only. Passwords are never shown here — and never stored where anyone can read them. When someone makes an account, Supabase scrambles their password into a one-way hash. Nobody can reverse it — not you, not me, not anyone with the database. That's what keeps people's accounts safe if the database ever leaks. If someone's locked out, send them a reset link and they'll pick a new password themselves.




To start recording accounts, run the new "Part 5 — clutch_accounts" block in supabase-tables.sql in the Supabase SQL Editor. Accounts made before that won't appear here (they're still in Supabase Auth → Authentication → Users, visible only to you in the dashboard).
